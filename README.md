# Talabat App Api:zap:
![Build Status](https://img.shields.io/badge/build-processing-brightgreen)

We Provide a delivery app Api.

Here the user can order staff from the markets in the app.

If the user have his/her own markets or business...

He/She can Join us now as a seller (Admin)...

And keep the delivery on the App.

## Tecnology :star:
![Build Status](https://img.shields.io/badge/frame_work-Laravel-darkred)

We're using **Laravel** frame work as our _Back-End_ Tech.

## Packages :fire:

- [JWT-Auth Package](https://jwt-auth.readthedocs.io/en/develop/laravel-installation/)
